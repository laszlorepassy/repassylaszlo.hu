Nevezetes hegyesszög kiválasztása

30° (π/6 rad)

Definíciók és pontos értékek

Szinusz (sin α)
1/2 = 0,5
szemközti / átfogó = a / c
Koszinusz (cos α)
3 / 2 ≈ 0,8660
melletti / átfogó = b / c
Tangens (tg α)
3 / 3 ≈ 0,5774
szemközti / melletti = a / b
Kotangens (ctg α)
3 ≈ 1,7321
melletti / szemközti = b / a
• Átfogó (c): a derékszöggel szemközti oldal (itt c = 1).
• Szemközti befogó (a): az α szöggel szemközti oldal: a = sin α.
• Melletti befogó (b): az α szög melletti befogó: b = cos α.
• Pitagorasz-tétel: a² + b² = c² → sin²(α) + cos²(α) = 1.

Nevezetes szögek az egységkörön (0°–360°)

45° (π/4 rad)

Pontos értékek az egységkörön (R = 1)

x koordináta = cos α
vízszintes vetület
y koordináta = sin α
függőleges vetület
Tangens = y / x (tg α)
érintő az x = 1 egyenesen
Síknegyed / helyzet
Az egységkörben a pont koordinátái: P(cos α; sin α). A kör pontjaira kattintva is közvetlenül kiválasztható a kívánt szög!

Hullámrajzolás az egységkörből (vízszintes vetítéssel)

α = 0° (0 rad)
sin α = 0,0000
cos α = 1,0000
Ugrás:
Miért vízszintes a vetítővonal mindkét hullámnál?
• Piros vektor és hullám (szinusz): Az egységkörön az α szögű pont magassága közvetlenül sin α. A piros szaggatott vonal ezt a magasságot vetíti vízszintesen a szinusz görbére.
• Kék vektor és hullám (koszinusz): Az egységkörön a koszinusz a pont vízszintes koordinátája (x = cos α). Mivel cos α = sin(α + 90°), a 90°-kal elforgatott kék sugár magassága pontosan megegyezik a koszinusz értékével! Így a kék szaggatott vonal is teljesen vízszintesen vetíti át az értéket a koszinusz görbére.
• Fáziskülönbség: A két görbe pontosan megegyezik alakban, de a koszinusz 90°-kal (π/2-vel) el van tolva a szinuszhoz képest.

Könnyű megjegyzési trükk a sin értékekre:

Sorban a gyökök számlálója 0, 1, 2, 3, 4, a nevező mindig 2:
• sin(0°) = 0 / 2 = 0
• sin(30°) = 1 / 2 = 1/2
• sin(45°) = 2 / 2
• sin(60°) = 3 / 2
• sin(90°) = 4 / 2 = 1
